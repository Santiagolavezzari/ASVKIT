# ASV Kit (Asistencia Visual Kit)

<details>
  <summary>🌐 <b>Read in English</b></summary>
  <br>
  
  **ASV Kit** is an assistive home automation system focused on improving the quality of life, safety, and independence of hearing-impaired individuals.

  Utilizing a network of wireless sensor nodes (detecting events like door openings or appliance vibrations) powered by the **ESP-NOW** protocol, the system centralizes data on a **Flask server (MVC architecture)**. The backend processes these signals to trigger visual alerts and real-time notifications, transforming everyday auditory cues into accessible visual stimuli.
</details>

<details>
  <summary>🇦🇷 <b>Leer en Español</b></summary>
  <br>
  
  **ASV Kit** es un proyecto de domótica asistiva enfocado en mejorar la calidad de vida, seguridad y autonomía de personas con discapacidad auditiva dentro del hogar. 

  A través de una red de nodos sensores inalámbricos (que detectan eventos como la apertura de puertas o vibración en electrodomésticos) comunicados mediante el protocolo **ESP-NOW**, el sistema centraliza la información en un servidor **Flask (arquitectura MVC)**. Este procesa las señales y activa alertas lumínicas y notificaciones visuales en tiempo real, transformando estímulos sonoros cotidianos en señales visuales accesibles.
</details>
